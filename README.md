# Personal Developer Portfolio Landing Page

This portfolio template is an exact replica of the dark neon blue theme portfolio (seen in `theanik06.github.io/portfolio` and the attached PDF).

## How to Customize:
1. Open `index.html` in VS Code or Notepad.
2. Change the name, bio, skills, and projects to match your background.
3. Replace `avatar.png` with your portrait photo.

## Free Deployment on GitHub Pages:
1. Create a new public repository on [GitHub](https://github.com) named `portfolio` or `<your-username>.github.io`.
2. Drag and upload all files (`index.html`, `style.css`, `script.js`, and `avatar.png`) to the repository.
3. Commit changes.
4. Go to **Settings** > **Pages** in your repository.
5. Under **Branch**, select `main` (or `master`) and click **Save**.
6. Wait 1-2 minutes, and your portfolio will be live for free!
